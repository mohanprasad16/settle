# Settle evaluation

Headline: 50 held-out random months (seeds 1000-1049, never used while building or tuning). They were already 50/50 perfect before the eval-bug fixes below. A finding is correct when its check and its amount to the paisa match.

The 19 adversarial edge cases are a **regression set**, not unseen data: they found five engine bugs, which were then fixed, so passing them now shows the fixes hold, not accuracy on new inputs. The 11 cases of **fresh batch 1** were written afterwards and run once blind (6/11, table kept below as it came out); the five failures were then fixed, so batch 1 is now a regression set too. **Fresh batch 2** (8 cases) was written after those fixes and run once; nothing was fixed for it.
